# chat_api WebSocket client

Generated by wsforge. Default endpoint: `ws://localhost:8080/ws`

```sh
npm install
```

```js
import { WsClient } from './client.js';
const client = await new WsClient().connect();
```

## Methods

- `messagesCreate(payload)` → `messages.create`
- `messagesDelete(payload)` → `messages.delete`
- `messagesGet(payload)` → `messages.get`
- `messagesList(payload)` → `messages.list`
- `messagesUpdate(payload)` → `messages.update`
- `roomsCreate(payload)` → `rooms.create`
- `roomsDelete(payload)` → `rooms.delete`
- `roomsGet(payload)` → `rooms.get`
- `roomsList(payload)` → `rooms.list`
- `roomsUpdate(payload)` → `rooms.update`
- `usersCreate(payload)` → `users.create`
- `usersDelete(payload)` → `users.delete`
- `usersGet(payload)` → `users.get`
- `usersList(payload)` → `users.list`
- `usersUpdate(payload)` → `users.update`
- `joinRoom(room)` / `leaveRoom(room)` / `sendRoom(room, data)`
- `on('room.message', fn)` for incoming room events
- `on(type, fn)` / `request(type, payload)` low-level API
